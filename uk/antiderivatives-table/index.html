    Первісна степеневої функції

    11 клас
    F(x)=xn+1n+1F(x) = \frac{x^{n+1}}{n+1}F(x)=n+1xn+1​

    Первісна (антипохідна) степеневої функції xⁿ при n ≠ −1.

    Позначення:
    • x — Значення x
    • n — Показник n

    Первісна константи

    11 клас
    F(x)=kx+CF(x) = kx + CF(x)=kx+C

    Первісна сталої величини k.

    Позначення:
    • k — Коефіцієнт k
    • x — Значення x

    Первісна функції 1/x

    11 клас
    F(x)=ln⁡∣x∣+CF(x) = \ln|x| + CF(x)=ln∣x∣+C

    Первісна функції, оберненої пропорційної x.

    Позначення:
    • x — Значення x

    Первісна функції 1/√x

    11 клас
    F(x)=2x+CF(x) = 2\sqrt{x} + CF(x)=2x​+C

    Первісна функції, оберненої квадратному кореню з x.

    Позначення:
    • x — Значення x

    Первісна синуса

    11 клас
    F(x)=−cos⁡x+CF(x) = -\cos x + CF(x)=−cosx+C

    Первісна функції синуса.

    Позначення:
    • deg — Кут x (у градусах)

    Первісна косинуса

    11 клас
    F(x)=sin⁡x+CF(x) = \sin x + CF(x)=sinx+C

    Первісна функції косинуса.

    Позначення:
    • deg — Кут x (у градусах)

    Первісна функції 1/cos²x

    11 клас
    F(x)=tg⁡x+CF(x) = \operatorname{tg} x + CF(x)=tgx+C

    Первісна функції, оберненої квадрату косинуса.

    Позначення:
    • deg — Кут x (у градусах)

    Первісна функції 1/sin²x

    11 клас
    F(x)=−ctg⁡x+CF(x) = -\operatorname{ctg} x + CF(x)=−ctgx+C

    Первісна функції, оберненої квадрату синуса.

    Позначення:
    • deg — Кут x (у градусах)

    Первісна показникової функції

    11 клас
    F(x)=axln⁡a+CF(x) = \frac{a^x}{\ln a} + CF(x)=lnaax​+C

    Первісна показникової функції з довільною основою a.

    Позначення:
    • a — Основа a (a>0, a≠1)
    • x — Значення x

    Первісна функції eˣ

    11 клас
    F(x)=ex+CF(x) = e^x + CF(x)=ex+C

    Первісна експоненціальної функції eˣ.

    Позначення:
    • x — Значення x
