    Number of permutations

    Grade 9
    Pn=n!P_n = n!Pn​=n!

    Number of ways to arrange n elements (n factorial).

    Legend:
    • n — Number of elements n (integer ≥ 0)

    Number of combinations C(n,k)

    Grade 9
    Cnk=n!k!(n−k)!C_n^k = \frac{n!}{k!(n-k)!}Cnk​=k!(n−k)!n!​

    Number of ways to choose k elements out of n, order not counted.

    Legend:
    • n — Number of elements (n)
    • k — Number chosen (k)

    Number of permutations A(n,k)

    Grade 9
    Ank=n!(n−k)!A_n^k = \frac{n!}{(n-k)!}Ank​=(n−k)!n!​

    Number of ways to choose and order k elements out of n.

    Legend:
    • n — Number of elements (n)
    • k — Number chosen (k)

    Grade 9
    P(A)=mnP(A) = \frac{m}{n}P(A)=nm​

    Probability of an event as the ratio of favourable outcomes to all outcomes.

    Legend:

    Probability that event A does not occur.

    ∣A∪B∣=∣A∣+∣B∣−∣A∩B∣|A \cup B| = |A| + |B| - |A \cap B|∣A∪B∣=∣A∣+∣B∣−∣A∩B∣

    Grade 11
    P(A∩B)=P(A)⋅P(B)P(A \cap B) = P(A) \cdot P(B)P(A∩B)=P(A)⋅P(B)

    Probability that two independent events both occur.

    Legend:
    • pa — Probability of event P(A)
