    О проекте

    Quantify — бесплатный справочник формул по математике для школьников 5–11 классов: алгебра, геометрия, тригонометрия, производные и интегралы. Быстрый поиск, встроенный калькулятор для каждой формулы и шпаргалка в один клик. Проект разрабатывается и поддерживается независимым разработчиком-энтузиастом.
