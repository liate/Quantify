    Сумма углов треугольника

    7 класс
    α+β+γ=180∘\alpha + \beta + \gamma = 180^\circα+β+γ=180∘

    Находит третий угол треугольника по двум известным.

    Обозначения:
    • alpha — Угол α (град)
    • beta — Угол β (град)

    Внешний угол треугольника

    7 класс
    α=β+γ\alpha = \beta + \gammaα=β+γ

    Внешний угол равен сумме двух внутренних углов, не смежных с ним.

    Обозначения:
    • beta — Угол β (град)
    • gamma — Угол γ (град)

    Обозначения:
    • b — Сторона b
    • c — Сторона c

    Теорема Фалеса (четвёртый пропорциональный отрезок)

    8 класс
    ab=cd⇒d=b⋅ca\frac{a}{b} = \frac{c}{d} \Rightarrow d = \frac{b \cdot c}{a}ba​=dc​⇒d=ab⋅c​

    Обозначения:
    • a — Отрезок a
    • b — Отрезок b
    • c — Отрезок c
