    Расстояние между двумя точками

    8 класс
    d=(x2−x1)2+(y2−y1)2d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}d=(x2​−x1​)2+(y2​−y1​)2​

    Длина отрезка между двумя точками на координатной плоскости.

    Обозначения:
    • x1 — Координата x первой точки
    • y1 — Координата y первой точки
    • x2 — Координата x второй точки
    • y2 — Координата y второй точки

    Середина отрезка (координаты)

    8 класс
    M(x1+x22, y1+y22)M\left(\frac{x_1+x_2}{2},\ \frac{y_1+y_2}{2}\right)M(2x1​+x2​​, 2y1​+y2​​)

    Координаты точки, делящей отрезок пополам.

    Обозначения:
    • x1 — Координата x первой точки
    • y1 — Координата y первой точки
    • x2 — Координата x второй точки
    • y2 — Координата y второй точки

    Скалярное произведение векторов

    9 класс
    a⃗⋅b⃗=x1x2+y1y2\vec{a} \cdot \vec{b} = x_1 x_2 + y_1 y_2a⋅b=x1​x2​+y1​y2​

    Скалярное произведение двух векторов на плоскости по координатам.

    Обозначения:
    • x1 — Координата x первого вектора
    • y1 — Координата y первого вектора
    • x2 — Координата x второго вектора
    • y2 — Координата y второго вектора

    Длина вектора по координатам

    9 класс
    ∣a⃗∣=x2+y2|\vec{a}| = \sqrt{x^2 + y^2}∣a∣=x2+y2​

    Длина (модуль) вектора на плоскости.

    Обозначения:
    • x — Координата x
    • y — Координата y

    Сумма векторов по координатам

    9 класс
    a⃗+b⃗=(ax+bx, ay+by)\vec{a}+\vec{b} = (a_x+b_x,\ a_y+b_y)a+b=(ax​+bx​, ay​+by​)

    Сложение векторов покоординатно.

    Обозначения:
    • a_x — Координата x вектора a
    • a_y — Координата y вектора a
    • b_x — Координата x вектора b
    • b_y — Координата y вектора b

    Косинус угла между векторами (2D)

    9 класс
    cos⁡φ=a⃗⋅b⃗∣a⃗∣∣b⃗∣\cos\varphi = \frac{\vec a \cdot \vec b}{|\vec a||\vec b|}cosφ=∣a∣∣b∣a⋅b​

    Косинус угла между двумя векторами на плоскости через их координаты.

    Обозначения:
    • a_x — Координата x вектора a
    • a_y — Координата y вектора a
    • b_x — Координата x вектора b
    • b_y — Координата y вектора b

    Угловой коэффициент прямой по двум точкам

    9 класс
    k=y2−y1x2−x1k = \frac{y_2-y_1}{x_2-x_1}k=x2​−x1​y2​−y1​​

    Угловой коэффициент прямой, проходящей через две заданные точки.

    Обозначения:
    • x1 — Координата x первой точки
    • y1 — Координата y первой точки
    • x2 — Координата x второй точки
    • y2 — Координата y второй точки

    Расстояние от точки до прямой

    9 класс
    d=∣Ax0+By0+C∣A2+B2d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}d=A2+B2​∣Ax0​+By0​+C∣​

    Кратчайшее расстояние от точки до прямой, заданной уравнением Ax+By+C=0.

    Обозначения:
    • A — Коэффициент a
    • B — Коэффициент b
    • C — Коэффициент c
    • x0 — Координата x0
    • y0 — Координата y0

    Радиус окружности по уравнению

    9 класс
    r=(x−a)2+(y−b)2r = \sqrt{(x-a)^2+(y-b)^2}r=(x−a)2+(y−b)2​

    Радиус окружности с центром (a,b), проходящей через точку (x,y).

    Обозначения:
    • x0 — Координата x0
    • y0 — Координата y0
    • x — Координата x
    • y — Координата y

    Разность векторов по координатам

    9 класс
    a⃗−b⃗=(ax−bx, ay−by)\vec a-\vec b = (a_x-b_x,\ a_y-b_y)a−b=(ax​−bx​, ay​−by​)

    Вычитание векторов покоординатно.

    Обозначения:
    • ax — a_x
    • ay — a_y
    • bx — b_x
    • by — b_y

    Скалярное произведение векторов (через модули и угол)

    9 класс
    A⃗⋅B⃗=∣a⃗∣⋅∣b⃗∣⋅cos⁡α\vec{A} \cdot \vec{B} = |\vec a| \cdot |\vec b| \cdot \cos\alphaA⋅B=∣a∣⋅∣b∣⋅cosα

    Скалярное произведение векторов через их длины и угол между ними.

    Обозначения:
    • a — Модуль вектора a (|a|)
    • b — Модуль вектора b (|b|)
    • alpha — Угол α (град)

    Угол между векторами в пространстве

    11 класс
    cos⁡θ=x1x2+y1y2+z1z2∣a⃗∣⋅∣b⃗∣\cos \theta = \frac{x_1 x_2 + y_1 y_2 + z_1 z_2}{|\vec{a}| \cdot |\vec{b}|}cosθ=∣a∣⋅∣b∣x1​x2​+y1​y2​+z1​z2​​

    Косинус угла между двумя трёхмерными векторами по их координатам.

    Обозначения:
    • a_x — Координата x первого вектора
    • a_y — Координата y первого вектора
    • a_z — Координата z первого вектора
    • b_x — Координата x второго вектора
    • b_y — Координата y второго вектора
    • b_z — Координата z второго вектора

    Длина вектора в пространстве

    11 класс
    ∣a⃗∣=x2+y2+z2|\vec a| = \sqrt{x^2+y^2+z^2}∣a∣=x2+y2+z2​

    Длина (модуль) вектора в трёхмерном пространстве по его координатам.

    Обозначения:
    • x — a_x
    • y — a_y
    • z — a_z
