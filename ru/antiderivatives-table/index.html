Таблица первообразных

    Первообразная степенной функции

    11 класс
    F(x)=xn+1n+1F(x) = \frac{x^{n+1}}{n+1}F(x)=n+1xn+1​

    Первообразная (антипроизводная) степенной функции xⁿ при n ≠ −1.

    Обозначения:
    • x — Значение x
    • n — Показатель n

    Первообразная константы

    11 класс
    F(x)=kx+CF(x) = kx + CF(x)=kx+C

    Первообразная постоянной величины k.

    Обозначения:
    • k — Коэффициент k
    • x — Значение x

    Первообразная функции 1/√x

    11 класс
    F(x)=2x+CF(x) = 2\sqrt{x} + CF(x)=2x​+C

    Первообразная функции, обратной квадратному корню из x.

    Обозначения:
    • x — Значение x

    Первообразная синуса

    F(x)=−cos⁡x+CF(x) = -\cos x + CF(x)=−cosx+C

    О проекте

    Quantify — бесплатный справочник формул по математике для школьников 5–11 классов: алгебра, геометрия, тригонометрия, производные и интегралы. Быстрый поиск, встроенный калькулятор для каждой формулы и шпаргалка в один клик. Проект разрабатывается и поддерживается независимым разработчиком-энтузиастом.
