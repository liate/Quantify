Арифметическая и геометрическая прогрессии

    n-й член арифметической прогрессии

    9 класс
    an=a1+(n−1)da_n = a_1 + (n - 1)dan​=a1​+(n−1)d

    Позволяет найти любой член арифметической прогрессии.

    Обозначения:
    • a1 — Первый член (a1)
    • n — Номер элемента (n)
    • d — Разность (d)

    Сумма первых n членов арифметической прогрессии

    9 класс
    Sn=a1+an2⋅nS_n = \frac{a_1 + a_n}{2} \cdot nSn​=2a1​+an​​⋅n

    Вычисляет сумму с 1-го по n-й члены арифметической прогрессии.

    Обозначения:
    • a1 — Первый член (a1)
    • an — n-й член (an)
    • n — Количество элементов (n)

    n-й член геометрической прогрессии

    9 класс
    bn=b1⋅qn−1b_n = b_1 \cdot q^{n-1}bn​=b1​⋅qn−1

    Позволяет найти любой член геометрической прогрессии.

    Обозначения:
    • b1 — Первый член (b1)
    • q — Знаменатель (q)
    • n — Номер элемента (n)

    Сумма первых n членов геометрической прогрессии

    9 класс
    Sn=b1(qn−1)q−1(q≠1)S_n = \frac{b_1 (q^n - 1)}{q - 1} \quad (q \neq 1)Sn​=q−1b1​(qn−1)​(q=1)

    Вычисляет сумму первых n членов геометрической прогрессии при q ≠ 1.

    Обозначения:
    • b1 — Первый член (b1)
    • q — Знаменатель q (q≠1)
    • n — Количество (n)

    Сумма n членов арифметической прогрессии (через первый член и разность)

    9 класс
    Sn=2a1+(n−1)d2⋅nS_n = \frac{2a_1 + (n-1)d}{2} \cdot nSn​=22a1​+(n−1)d​⋅n

    Вычисляет сумму первых n членов арифметической прогрессии через первый член и разность.

    Обозначения:
    • a1 — Первый член (a1)
    • n — Количество (n)
    • d — Разность (d)

    Характеристическое свойство геометрической прогрессии

    9 класс
    bn2=bn+1⋅bn−1b_n^2 = b_{n+1} \cdot b_{n-1}bn2​=bn+1​⋅bn−1​

    Квадрат члена геометрической прогрессии равен произведению соседних с ним членов.

    Обозначения:
    • bnext — Следующий член (b_{n+1})
    • bprev — Предыдущий член (b_{n-1})

    Характеристическое свойство арифметической прогрессии

    9 класс
    an=an−1+an+12a_n = \frac{a_{n-1}+a_{n+1}}{2}an​=2an−1​+an+1​​

    Каждый член арифметической прогрессии равен среднему арифметическому соседних членов.

    Обозначения:
    • aprev — Предыдущий член (a_{n-1})
    • anext — Следующий член (a_{n+1})

    Разность арифметической прогрессии (через два произвольных члена)

    9 класс
    d=an+1−an=an−akn−kd = a_{n+1} - a_n = \frac{a_n - a_k}{n - k}d=an+1​−an​=n−kan​−ak​​

    Разность арифметической прогрессии через любые два её члена и их номера.

    Обозначения:
    • an — Член a_n
    • ak — Член a_k
    • n — Номер n
    • k — Номер k

    n-й член арифметической прогрессии (через произвольный k-й член)

    9 класс
    an=ak+(n−k)da_n = a_k + (n - k)dan​=ak​+(n−k)d

    Любой член арифметической прогрессии можно найти не только через первый, но и через любой другой известный член.

    Обозначения:
    • ak — Член a_k
    • n — Номер n
    • k — Номер k
    • d — Разность (d)
